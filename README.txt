TvClicker — TV-themed clicker game

Open index.html in a browser to play. Click the retro television to earn TV points, buy upgrades, automate production, and rebirth for a permanent multiplier. The layout uses an incremental-clicker shop design with original TV-themed styling.

Included: upgrades, auto production, rebirths, achievements, redeem codes, random events, owner tools, automatic Supabase anonymous sign-in, and shared announcements/global events.

To connect Supabase, follow README-SUPABASE-SETUP.md and replace the placeholders in supabase-config.js with your project's URL and anon/publishable key. Never put a service-role key in browser code.

Global: announcements and admin-started events. Local: each player's TV point balance, upgrades, rebirths, and achievements. A shared leaderboard/player directory is not included in this build.
