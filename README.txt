Jayz Candy Clicker update

Open index.html in a browser to play.

Changes:
- Announcements now save with the game's browser save and restore after reload.
- Announcement changes sync between open tabs using the same browser storage.
- Added Thanksgiving Eating to the admin event selector; it gives at least 10x candy.
- Random event check runs every 10 minutes: Thanksgiving Eating has a 30% chance, Trick-or-Treat has a 10% chance, and otherwise no event starts.
- Both random events last 30 seconds and give 10x candy.

Note: This is still a browser-only game. Announcements and admin-started events are local to a player's browser; truly shared announcements/events for all visitors require a server/backend.
